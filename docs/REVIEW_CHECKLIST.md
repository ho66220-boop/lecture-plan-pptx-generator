# PPTX 육안 검수 체크리스트

자동 검증(validation_report)이 좁혀 준 대상부터 보고, 그다음 공통 항목을 확인합니다.
레이아웃(겹침·잔존 칸·크롭)은 pytest가 못 잡는 영역이라 **이 검수가 마지막 방어선**입니다.

## 0. 시작 전

- [ ] `validation_report.xlsx`를 연다 (열리지 않으면 `_재시도HHMMSS`가 붙은 대체명 파일 확인).
- [ ] 콘솔의 severity별 건수(report_counts)로 전체 상태 파악 — **오류 > 확인필요 > 경고** 순으로 처리.

## 1. 리포트 기반 우선 검수 — 해당 슬라이드를 먼저 연다

리포트가 검수 대상을 좁혀 주는 구조입니다. 아래 코드가 있으면 해당 `source_file/source_sheet` 슬라이드부터:

- [ ] **오류 행 전부** — `DATE_PARSE_FAILED` / `PROGRESS_DATE_MISSING`(회차·수강료가 입력 의도와 다를 수 있음 → 강사에게 날짜 수정 요청 후 재실행이 원칙), `LECTURE_NORMALIZE_FAILED` / `PPTX_GENERATION_FAILED`(그 강좌 슬라이드가 아예 없음 — 입력 확인 후 재실행), `OUTPUT_SAVE_FAILED`(pptx 미생성 — 파일 닫고 재실행).
- [ ] **`A4_OVERFLOW`** — 본문이 하한 폰트로도 한 장 초과. 하단 잘림 여부 확인, 강사에게 분량 축소 요청.
- [ ] **`TITLE_OVERFLOW`** — 제목이 14pt로도 2줄 초과. **제목과 강의개요 겹침** 확인, 필요 시 수동 조정.
- [ ] **`OUT_OF_ORDER_DATE`** — 진도 날짜 역행. 보강 삽입이면 OK, **해를 넘긴 날짜면 강사에게 연도 명시 요청**(수강기간·수강료 확인).
- [ ] **`BILLING_UNDETERMINED`** — 구분·시즌 공백 → 월 단위로 가정됨. **특강이면 오청구** — 구분 입력 후 재실행.
- [ ] **`WEEKDAY_MISMATCH`** — 입력 요일 ≠ 실제 요일. 날짜가 맞는지 강사 확인.
- [ ] **`TEACHER_PHOTO_NOT_FOUND` / `TEACHER_PHOTO_INSERT_FAILED`** — 회색 박스 슬라이드. 사진 파일명(강사명 일치)·손상 여부, 파일이 있다면 템플릿 사진박스 위치(TEMPLATE_GUIDE 2절) 확인.
- [ ] **`UNMAPPED_PLACEHOLDER`** — 템플릿 계약 위반(전 슬라이드 영향). TEMPLATE_GUIDE 1절 표와 대조.
- [ ] `TEXT_LIMIT_EXCEEDED` / `PROGRESS_OVERFLOW` / `FEE_TABLE_MISSING` / `ACADEMIC_CALENDAR_CONFLICT` / `SESSION_TYPE_REVIEW_NEEDED` / `OPENING_TIME_PARSE_FAILED` — 행별 suggestion 컬럼 지시대로.

## 2. 공통 육안 확인 (전 슬라이드 훑기, 리포트로 안 잡히는 것들)

- [ ] **제목**: 2줄 이내, 아래 강의개요와 겹침 없음.
- [ ] **진도표**: 빈 칸 잔존 없음(안 쓰는 칸은 삭제되어야 정상), 날짜·내용 칸 높이 맞음, 글자 겹침 없음.
- [ ] **진도 색**: 휴강 행 **빨강**, (월별 계획서) 다음 달 미리보기 행 **회색**.
- [ ] **사진**: 크롭이 어색하지 않은지(가운데 기준), 회색 박스 잔존 없는지.
- [ ] **과목 색 띠**: 국어=빨강 / 수학=노랑 / 영어=주황 / 사탐=초록 / 과탐=파랑 / 논술=보라 — 과목과 일치.
- [ ] **수강료 표기**: 정규반 `월 N원 (회차당 n원)` / 특강 `N원 (회차당 n원)` — 강좌 성격과 청구 단위 일치.
- [ ] **배지·과목·강사명**: 칸 밖으로 삐져나온 글자 없음(배지 하한 클립은 리포트가 없음).

## 3. 마무리

- [ ] 인쇄 미리보기(A4 세로)로 2~3장 샘플 확인.
- [ ] 수정 요청 목록을 강사/교무팀에 전달, 재실행 필요 여부 결정(입력을 고쳤다면 재실행이 원칙 — 수기 수정은 사소한 표현만).
