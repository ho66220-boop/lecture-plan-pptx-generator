# 템플릿 수정 가이드 — 지켜야 할 불변식

`templates/강의계획서_마스터템플릿.pptx`를 수정할 때 코드가 전제하는 조건들입니다.
**일부 위반은 리포트로 잡히지만, 상당수는 크래시 없이 조용히 깨집니다** — 후자가 이 문서가 존재하는 이유입니다.
각 조건의 근거 상수는 소스 파일명과 함께 적었으니, 값이 의심되면 코드가 진실입니다.

## 1. Placeholder 목록 (템플릿 ↔ 코드 계약)

템플릿 첫 슬라이드의 `{{키}}`는 아래 36개입니다(실제 템플릿에서 추출, `build_placeholder_map`과 대조 완료).

**일반 16개:**

| placeholder | 값의 출처(입력 엑셀 필드 → 가공) |
|---|---|
| `{{강좌유형}}` `{{구분}}` `{{학년}}` `{{강의형태}}` | 동명 필드 그대로 |
| `{{과목}}` | 과목 → 정규화(수학 세부과목→`수학`, 수준표기 제거) |
| `{{강사명}}` | 강사명 그대로(사진 매칭에도 사용) |
| `{{메인제목}}` | **강좌명**(큰 제목) |
| `{{서브슬로건}}` | 메인 제목(강좌명과 다를 때) 또는 서브 슬로건 |
| `{{개강일}}` | 진도표 첫 수업일 + 수업 시작 시간(자동 계산) |
| `{{수업시간}}` | 수업 요일 / 시간 |
| `{{수강기간}}` | 진도표 첫·끝 수업일(자동 계산) |
| `{{수강료}}` | 자동 계산(월 단위/전체 합계) |
| `{{보강방법}}` `{{교재정보}}` `{{강의특징}}` `{{관리프로그램}}` | 동명 필드 |

**진도 슬롯 20개:** `{{진도_좌_1_날짜}}`~`{{진도_좌_5_날짜}}`, `{{진도_우_1_날짜}}`~`{{진도_우_5_날짜}}` 및 대응 `_내용` — 좌 5 × 우 5 × (날짜·내용).

**추가로 쓸 수 있는 키 2개(현재 템플릿 미사용):** `{{강좌명}}`, `{{휴강일}}` — map에는 있으므로 템플릿에 넣으면 치환됩니다.

- **위반하면:** 키 이름 오타·개명·목록에 없는 새 키 → 실행 시 `UNMAPPED_PLACEHOLDER`(확인필요) 리포트로 **잡힙니다**(실행당 키당 1회). 단 값은 빈칸으로 렌더되므로 리포트를 보고 고쳐야 합니다.
- 키를 **삭제**하면(예: `{{수강료}}` 박스 제거) 그 값이 아무 데도 안 나오는데 **리포트가 없습니다** — 삭제는 의도일 수도 있어 코드가 판단하지 않습니다. 삭제 시 이 표를 갱신하세요.

## 2. 사진박스 (조용히 깨짐 주의)

우상단 강사 사진박스는 **위치·크기로 식별**합니다(`src/teacher_photo.py`의 `is_photo_box`):

| 조건 | 값 |
|---|---|
| 상단에서 | top < **2.0cm** |
| 오른쪽에서 | left > **13.5cm** |
| 최소 크기 | 한 변 > **3.0cm** |
| 정사각 판정 | \|가로−세로\| < **0.5cm** |

- **위반하면:** 사진 파일이 있어도 박스를 못 찾아 회색 박스로 남고 `TEACHER_PHOTO_NOT_FOUND`가 뜹니다. 메시지에 "사진박스 미식별 가능성"이 안내되지만, **원인이 파일인지 박스인지는 사람이 구분**해야 합니다. 박스를 옮겼다면 위 임계도 함께 조정하세요.
- 이 술어는 reflow에서도 쓰입니다(사진박스는 세로 확장 대상에서 제외 — 정사각 유지).

## 3. 진도 그리드 (조용히 깨짐 — 최대 주의)

진도표는 **5행 × 2열(좌/우)** 구조를 위치 기반으로 인식합니다(`src/generate_pptx.py`):

- 섹션 제목 텍스트에 **"주차별 진도"** 문구가 있어야 합니다(앵커). 문구를 바꾸면 안 쓰는 칸 삭제가 통째로 건너뛰어져 **빈 진도칸이 조용히 잔존**합니다.
- 행 클러스터링 임계 **0.45cm**(`PROGRESS_ROW_GAP_CM`): 같은 행의 도형 간 세로 간격은 이보다 작게, 행 사이 간격은 이보다 크게 유지해야 합니다.
- 좌/우 컬럼은 도형 left 값의 **가장 큰 간격**으로 갈라집니다 — 열 사이 여백이 열 내부 여백보다 커야 합니다.
- 한 컬럼 최대 **5행**(`PROGRESS_MAX_PER_COL`) — 행 수를 바꾸면 코드 상수와 좌우 분배(`progress_split`)도 함께 바꿔야 합니다.
- **위반하면:** 채운 칸이 삭제되거나 빈 칸이 남는 **조용한 오배치**. 리포트 없음 — 반드시 렌더 육안 검수(`docs/REVIEW_CHECKLIST.md`)로 확인하세요.

## 4. 레이아웃 경계·제목·배지

- **FIT_TITLE_GUARD = 5.0cm**: 슬라이드 상단 5cm 위 영역(배지·제목·과목)은 A4 넘침 시 폰트 축소 **대상에서 제외**됩니다. 본문 요소를 5cm 위로 올리면 축소가 안 되고, 제목류를 5cm 아래로 내리면 본문과 함께 축소됩니다 — 조용한 레이아웃 변화.
- **큰 제목 박스**: 폭 ≥ 10cm + 기본 폰트 ≥ 16pt인 박스를 제목으로 간주, 최대 **2줄**·최소 **14pt**까지 축소. 하한에서도 넘치면 `TITLE_OVERFLOW`(확인필요)로 **잡힙니다**.
- **배지(한 줄 박스)**: 폭 ≤ 4.5cm, 폰트 하한 **7pt** — 하한 초과 클립은 **리포트 없음**(조용).

## 5. 폰트 교체 절차 (GLYPH_W_* 재측정)

줄 수 추정·가로 맞춤은 글자 폭 비율 상수에 의존합니다(`src/reflow.py`):

```python
GLYPH_W_KO = 0.88      # 한글 음절 폭 / 폰트 pt (현재 폰트 실측값)
GLYPH_W_ASCII = 0.61   # ASCII 평균 폭 / 폰트 pt
```

폰트를 바꾸면:
1. 새 폰트로 **PIL 실측**: `ImageFont.truetype(폰트, pt)` 후 `getlength("가")/pt`(한글), `getlength(ASCII 표본 평균)/pt`.
2. `src/reflow.py`의 두 상수 갱신.
3. `tests/test_pure_functions.py`의 **비율 잠금 테스트**(`test_est_lines_wrapping_locks_ratio`) 기대값 갱신 — 이 테스트가 무단 변경을 막는 장치입니다.
4. 스트레스 입력(2줄 제목·6~7줄 진도)으로 렌더 육안 확인.
- **위반하면(재측정 생략):** 줄 수 추정이 틀어져 박스가 넘치거나 과확장 — 리포트 없음, 육안으로만 보임.

## 6. 기타 구조 전제

- **첫 슬라이드가 마스터**: 강좌 수만큼 첫 슬라이드를 복제합니다. 슬라이드가 0장이거나 레이아웃이 없으면 명확한 메시지로 **즉시 실패**(잡힘).
- 템플릿 파일 자체가 없거나 손상 → 즉시 실패(잡힘).

## 수정 후 확인 루틴

1. 예시 입력으로 1회 실행 → `validation_report.xlsx`에서 `UNMAPPED_PLACEHOLDER`·`TITLE_OVERFLOW` 확인.
2. `pytest tests/` 통과 확인.
3. 렌더 육안 검수(`docs/REVIEW_CHECKLIST.md`) — 특히 3절(그리드)·2절(사진박스)은 리포트가 못 잡으므로 필수.
