# Lecture Plan PPTX Generator

강의계획서 PPTX 제작 과정에서 반복되는 수작업 입력을 줄이기 위해 업무 지시 없이 개인적으로 기획·개발한 자동화 도구입니다. 반복 작업의 비효율을 직접 목격하고, 근무 외 시간에 파이프라인을 설계·구현했습니다. 강사 입력 엑셀을 읽어 강의계획서 PPTX 초안, 정규화 데이터, 검증 리포트를 생성합니다. 완성본 생성기가 아니라 교무팀 검수 전 초안 생성 도구입니다.

> 본 프로젝트는 직접 설계·구현했으며, 코드 리팩토링과 디버깅 과정에서 Claude Code를 활용했습니다.

## 문제 정의

학원에서는 매 시즌 강사별 강의계획서 PPTX를 제작합니다. 기존 프로세스에는 세 가지 문제가 있었습니다.

- **반복 수작업**: 강사가 보내온 비정형 자료(한글 파일, 메신저 텍스트, 손글씨 사진 등)를 교무팀이 PPTX에 일일이 옮겨 적어야 했습니다. 강좌 수가 늘수록 작업 시간이 선형으로 증가합니다.
- **입력 오류**: 날짜·요일 불일치, 휴강일과 진도표 충돌, 수강료 계산 실수 같은 오류가 사람 눈 검수에만 의존했습니다. 특히 수강료는 틀리면 환불·민원으로 직결되는 항목입니다.
- **양식 비표준**: 강사마다 보내는 자료 형식이 달라 "어디에 뭘 써야 하는지" 매번 커뮤니케이션 비용이 발생했습니다.

## 해결 접근

문제를 "PPTX를 자동으로 그리는 것"이 아니라 **입력 표준화 → 검증 → 초안 생성**의 3단계 파이프라인으로 정의했습니다.

1. **입력 표준화**: 강사가 직접 채우는 표준 엑셀 양식(강좌별 카드 시트)을 설계해, 비정형 자료 수집 단계를 구조화된 데이터 수집으로 바꿨습니다.
2. **자동 검증**: 날짜 파싱 실패, 요일 불일치, 학사일정 충돌, 글자 수 초과 등을 실행 중단 없이 `validation_report.xlsx`에 수집합니다. 오류가 있어도 파이프라인은 끝까지 돌고, 사람은 리포트만 보고 수정 지점을 찾습니다.
3. **초안 생성**: 마스터 템플릿의 placeholder를 치환해 PPTX 초안을 만들고, 글자 수에 맞춰 텍스트 박스·배경을 자동 확장(reflow)한 뒤 A4 한 장에 맞도록 본문 폰트를 조정합니다. 개강일·총회차·수강기간·수강료는 진도표에서 자동 계산합니다.

설계 원칙은 두 가지였습니다.

- **자동화는 초안까지, 판단은 사람이**: FAQ처럼 강사별 편차가 큰 영역은 자동 생성 대상에서 제외하고 수동 작성 영역으로 남겼습니다.
- **인수인계 가능한 구조**: 수강료표·학사일정·글자 수 제한 같은 운영 값은 `config/`로 분리해 코드 수정 없이 바꿀 수 있게 했습니다(레이아웃·폰트 상수는 템플릿과 강결합이라 의도적으로 코드에 둡니다 — [docs/TEMPLATE_GUIDE.md](docs/TEMPLATE_GUIDE.md) 참조).

## 결과

- **처리 규모**: 매달 강사 약 40명, 강좌 약 100개 분량의 강의계획서를 처리합니다.
- **건당 소요 시간**: 수작업 입력 약 3~60분(자료 복잡도에 따라 편차) → 표준 엑셀 입력 후 생성은 1분 미만, 사람은 검수에 약 10분만 사용합니다.
- 날짜·요일·수강료 오류를 생성 전 검증 리포트에서 일괄 검출 (사람 눈 검수 의존 → 시스템 검출 + 사람 최종 확인)
- 교무팀 역할이 "옮겨 적기"에서 "최종 검수·미세 수정"으로 전환

## 기술 하이라이트

- **검증 리포트 설계**: severity(오류/경고/확인필요/정보) · issue_code · raw_value · computed_value · suggestion 컬럼 구조. 오류가 나도 멈추지 않고 끝까지 수집하는 정책으로, 사용자(교무팀)가 한 번에 모든 수정 지점을 파악할 수 있습니다.
- **텍스트 reflow + A4 맞춤**: 치환 후 글자 폭 기반으로 줄 수를 근사 추정해, 넘치는 박스와 같은 행의 배경 셀·테두리를 함께 확장하고 아래 요소를 연쇄적으로 내립니다. 슬라이드는 A4로 고정하고, 내용이 넘치면 본문 폰트를 차등 축소(강의특징/관리는 먼저, 정보·진도표는 가독성 하한 유지)하며 그래도 넘치면 리포트에 기록합니다. (`src/reflow.py`, `src/generate_pptx.py`)
- **한국어 실데이터 정규화**: "현장강의"/"현장 강의" 공백 변형, 강사명·소스 파일명 NFC 정규화, 과목 표기 통일(로마자/숫자 수준표기 제거, 수학 세부과목→`수학`), "5/4(월)"·"5월 4일"·ISO 등 멀티 날짜 패턴 파싱, 요일 불일치 검출.
- **테스트**: 순수 함수 단위 테스트(날짜 파싱·수강료 우선순위·리플로우 추정)에 더해, 예시 엑셀을 파이프라인에 통째로 넣어 계산 결과를 스냅샷 검증하는 **골든 파일 E2E 테스트**, 진도표 헤더 훼손·강좌 단위 예외 격리·침묵 오염(순서 어긋난 날짜, 병합으로 빈 날짜) 시나리오 테스트를 포함합니다(총 118개, GitHub Actions CI에서 자동 실행).

## 사용 흐름

### Colab (권장)

1. `notebooks/강의계획서_자동화.ipynb`를 Colab에서 엽니다.
2. 셀을 순서대로 실행합니다. 입력 엑셀은 실행 중 업로드(여러 개 동시 가능)합니다.
3. 모든 강좌가 합쳐진 통합 PPTX 결과 zip을 내려받아 최종 검수합니다.

### 로컬 (CLI)

```bash
pip install -r requirements.txt
python -m src.pipeline --input-path input/예시_홍길동_강의계획서.xlsx --output-dir output --base-year 2026

# 정규반 월별 계획서(예: 7월): --target-month 7
python -m src.pipeline --input-path input/예시_홍길동_강의계획서.xlsx --output-dir output --base-year 2026 --target-month 7
```

생성 결과:

- `output/generated_pptx/강의계획서_초안_YYYYMMDD_HHMM.pptx`
- `output/normalized_data.xlsx` / `.json`
- `output/validation_report.xlsx`

## 처리 규칙

- 진도표 헤더는 공백·괄호 주석 변형(예: `상세내용`, `날짜(요일)`)을 허용하고, 5칸 중 4칸 이상 일치하면 인식합니다. 헤더를 못 찾은 시트는 조용히 버리지 않고 `PROGRESS_HEADER_NOT_FOUND` **오류**로 리포트에 남깁니다(회차·수강료 미계산 경고).
- 강좌 시트는 **이름·위치와 무관하게** 인식합니다(강사가 과목·이름으로 시트명을 바꾸거나, 안내·예시 시트를 지우거나 순서를 바꿔도 됨). 숨김 시트(선택목록 등)·이름에 `안내`·`예시`·`샘플`·`선택목록`이 든 시트, 그리고 빈 시트는 제외합니다. 입력 엑셀 **파일명도 무관**합니다(폴더 업로드 시 `.xlsx`이고 `~$` 임시잠금 파일만 아니면 됨).
- 진도표 날짜를 기준으로 개강일·총회차·수강기간·수강료를 자동 계산합니다. 수강료는 정규반이면 **월 단위**(한 달 회차수 기준), 특강·썸머이면 **강좌 전체 합계**로 산출합니다(`구분`/`시즌` 기준 판별).
- 날짜 파싱 실패, 요일 불일치, 학사일정 충돌, 긴 텍스트 등은 실행을 중단하지 않고 검증 리포트에 남깁니다.
- PPTX는 `templates/강의계획서_마스터템플릿.pptx`의 첫 슬라이드를 강좌 수만큼 복제한 뒤 `{{필드명}}` placeholder를 치환합니다.
- 치환 후 `src/reflow.py`가 글자 수에 맞춰 박스를 자동 확장합니다. placeholder 값 박스는 세로 중앙 정렬하고 상·하 여백(`PAD`)을 둡니다. 줄높이·여백 상수는 `src/reflow.py` 상단(`LINE_SLOT`, `PAD`)에서 조정합니다.
- FAQ 영역은 템플릿에서 제거되어 자동 생성물에 포함되지 않습니다(강사별로 달라 하단 여백을 수동 작성용으로 둠).
- 우상단 사진 박스에는 강사 사진을 자동으로 채웁니다(`src/teacher_photo.py`). `teacher_photos/`에 `강사명.jpg` 형식으로 넣으면 엑셀의 `강사명`과 매칭하며, 없으면 회색 박스로 두고 `TEACHER_PHOTO_NOT_FOUND`로 표시합니다.
- 슬라이드 테두리에는 `과목`별 색 띠를 두릅니다(`src/subject_band.py`). 국어=빨강 / 수학=노랑 / 영어=주황 / 사탐=초록 / 과탐=파랑 / 논술=보라이며, 세부 과목명(생명과학·생활과윤리·수리논술 등)도 키워드로 6계열에 매핑합니다.
- 엑셀을 여러 개 입력하면(또는 폴더를 지정하면) 모든 강좌를 **하나의 통합 PPTX**에 슬라이드로 모읍니다.
- 템플릿의 `{{키}}`가 치환 맵에 없으면(오타·개명 등) 생성 전에 대조해 `validation_report.xlsx`에 `UNMAPPED_PLACEHOLDER`로 기록합니다(실행당 키당 1회).

## 수강료 설정

`config/defaults.py`에서 관리합니다.

- `FEE_TABLE` — 강의형태별 회차당 수강료
- `FEE_PER_SESSION_OVERRIDES` — 강사명 기준 회차당 예외(강의형태 표보다 우선)
- `FEE_OVERRIDES` — 총액 예외. 키는 `"강사명|강좌명"`(공백 무시) 안정 키를 사용합니다. 시트명은 강사가 자유롭게 바꿀 수 있어 키로 쓰지 않습니다. 수집 순서 기반 `lecture_id`(L001_…)는 파일 추가 시 번호가 밀려 예외가 다른 강좌에 붙을 수 있어 안정 키로 대체했습니다(구 키도 하위 호환 조회).

청구 단위는 `구분`/`시즌`으로 판별합니다.

- **정규반**: `회차당 단가 × 한 달 회차수`(월 단위). 예: 7~8월 주 1회(월 4회) → `월 320,000원`
- **특강·썸머·윈터**: `회차당 단가 × 전체 회차`(강좌 전체 일괄 수강). `구분`/`시즌` 어디에 `특강`을 적든, 시즌에 `썸머`/`윈터`만 적어도 특강으로 인식합니다.

## 월별 계획서 (정규반)

정규반은 매달 따로 등록·결제하므로, 강좌 전체 기간이 아니라 **대상 월 한 달치**로 계획서를 뽑을 수 있습니다. `--target-month 7`(또는 Colab의 `TARGET_MONTH = 7`)을 주면:

- **정규반**: 진도표를 그 달(`base_year`의 해당 월)만 잘라, 개강일·총회차·수강기간·수강료를 그 달 기준으로 재계산합니다. 그 달에 수업이 0회인 정규반은 슬라이드를 만들지 않습니다.
- **특강**: 패키지 단위(썸머·윈터)라 월로 쪼개지 않고 **전체 기간 그대로 항상 포함**합니다(엑셀에 있으면 어느 달을 뽑든 노출).
- **다음 달 미리보기**: 진도표에 다음 달 행을 **회색**으로 함께 보여줘 커리큘럼을 안내합니다. 단, 회차·수강료·기간 누적에는 넣지 않아 청구는 그 달 기준 그대로입니다(12월 → 다음 해 1월 경계도 처리). 다음 달 휴강 행은 빨간색 휴강 표기를 유지합니다.
- 결과 파일명에 대상 연·월이 붙어(예: `강의계획서_초안_2026_07_...`) 월끼리 덮어쓰지 않습니다.
- `--target-month`를 생략하면 기존처럼 전체 기간·전 강좌 계획서를 만듭니다.

기본 샘플은 `config/academic_calendar_sample.csv`이며, `--academic-calendar-path`로 다른 파일을 지정할 수 있습니다.

## 실무 적용 중 발견한 문제와 대응

초안 도구를 실제 시즌 업무에 투입하면서, 테스트 데이터로는 드러나지 않던 문제들이 나왔습니다. 대부분 **"사용자가 설마 이렇게까지 입력하진 않을 것"이라는 내 가정이 깨진** 경우였습니다. `증상(누가 어떻게 써서 뭐가 깨졌나) → 원인(어떤 가정이 틀렸나) → 대응(코드/입력규칙/안내 중 무엇을 바꿨나)` 순으로 기록하며 고쳐 나가고 있습니다.

**과목 표기가 제각각 — `물리학Ⅰ`, `미적분`, `통합과학2`**
- 증상: 강사가 과목칸에 로마자 수준표기(`물리학Ⅰ`)·세부 과목(`미적분`, `확률과 통계`)을 그대로 적어 슬라이드 과목 배지에 길게 노출됨.
- 원인: 과목이 `물리학`·`수학`처럼 정제된 형태로 들어온다고 가정. 표기 규칙은 강사마다 달랐음.
- 대응(코드): 끝의 수준표기(아라비아 1/2/3·전각·로마자 Ⅰ/Ⅱ/Ⅲ) 제거, 수학 세부 과목은 `수학`으로 통일.

**긴 값이 박스를 튀어나옴 — `중3(예비고1)`, 긴 강좌명**
- 증상: 학년에 `중3(예비고1)`, 강좌명에 `[물리학Ⅰ] 실전300 + 특모 시즌2 + 오메가 모의고사`처럼 길게 입력하니 배지·제목 칸 밖으로 글자가 삐져나옴.
- 원인: 배지는 2~3글자(`수능`/`정시`), 제목은 한 줄이라고 가정하고 폭·높이를 고정.
- 대응(코드+템플릿): 박스 확대 + 폭 초과 시 폰트 자동 축소. 제목 박스는 키워 큰 글씨 그대로 최대 2줄까지 허용.

**진도 내용이 길면 글자가 겹쳐 뭉개짐 — 영어 한 칸 6~7줄**
- 증상: 한 회차 내용이 6~7줄인 강사의 진도표에서 칸이 안 커지고 줄이 겹쳐 읽을 수 없게 됨, 날짜칸과 내용칸 높이도 안 맞음.
- 원인: 한 칸 내용이 짧다고 가정 + 행 높이 조정 코드에서 내용 배경칸을 빠뜨린 자체 버그(행 간격 < 칸 높이 → 겹침).
- 대응(코드+템플릿): 한 행의 네 칸(날짜·내용 × 배경·글상자)을 동일 높이로 묶고, 내용에 맞춰 글상자까지 함께 확장.

**소스 파일명(강사 이름)이 깨져 보임**
- 증상: 검증/정규화 엑셀의 `source_file` 컬럼에서 강사 이름만 자모가 분리돼 깨짐(같은 시트의 다른 한글은 멀쩡).
- 원인: 업로드 파일명이 NFC라고 가정. macOS에서 만들어진 파일명이 NFD(자모 분해)로 들어옴.
- 대응(코드): 파일명·시트명을 캡처 지점에서 NFC로 정규화.

**본문 많은 강사는 A4 한 장을 넘김**
- 증상: 강의특징·관리 문구가 긴 강사의 슬라이드가 한 장을 초과.
- 원인: 내용이 많으면 슬라이드 높이를 늘리면 된다고 가정. 실제 배포는 A4 한 장 인쇄가 전제였음.
- 대응(코드+안내): A4 고정 + 본문 폰트 차등 축소(정보·진도는 가독성 하한 유지), 그래도 넘치면 리포트에 `A4_OVERFLOW`로 남겨 수동 축약을 유도.

**날짜 칸이 숫자로 깨져 들어옴 — `46225`**
- 증상: 한 강사 파일의 8개 강좌 전체에서 회차 0·수강료 공백. 날짜 칸에 `46225` 같은 정수만 보임.
- 원인: 날짜는 텍스트로 들어온다고 가정. 셀 서식이 풀리면 엑셀이 날짜를 1900년 기준 일련번호로 저장함.
- 대응(코드): 날짜 칸의 순수 숫자 중 현대 강의 날짜 범위(일련번호 40000~60000)에 드는 값만 날짜로 복구. 회차 수·연도 단독 같은 숫자는 범위 밖이라 오변환 없음.

**진도표 헤더를 살짝 고쳐 쓰면 강좌가 통째로 사라짐**
- 증상: 헤더를 `상세 내용`→`상세내용`처럼 바꾼 시트에서 진도가 조용히 사라져 회차·수강료가 0으로 계산됨(리포트도 없음).
- 원인: 헤더 5칸의 정확 일치를 가정. 강사는 공백·괄호 주석을 자유롭게 바꿈.
- 대응(코드): 공백·괄호 무시 + 5칸 중 4칸 일치로 완화 인식, 그래도 못 찾으면 `PROGRESS_HEADER_NOT_FOUND` 오류로 크게 표시(침묵 실패 금지).

**코드 감사에서 배운 것 — 위험한 건 크래시가 아니라 "조용한 오염"이었다**
- 증상: 전체 코드 감사 결과, 크래시보다 **리포트 없이 틀린 값이 최종 PPTX까지 흘러가는 경로**가 진짜 위험이었음. 예: 진도표 중간에 끼워 넣은 보강 행(월 역행)을 연도 경계로 오인해 이후 날짜가 전부 다음 해로 밀리고 수강료가 반토막 — 리포트 0건.
- 원인: "진도표는 시간순"이라는 가정 + 오류 처리의 초점이 예외(크래시)에만 있었음.
- 대응(코드): ① 애매하면 값을 자동 보정하지 않고 리포트하는 원칙으로 전환(`OUT_OF_ORDER_DATE`, `PROGRESS_DATE_MISSING`, `BILLING_UNDETERMINED` 등 탐지 리포트 추가), ② 강좌 1건의 예외가 배치 전체를 죽이지 않게 강좌 단위 격리, ③ 어떤 예외 경로에서도 검증 리포트 파일은 남도록 보존 — 수정마다 실패 테스트를 먼저 작성해 회귀를 잠갔습니다.

**레이아웃이 실제 운영 양식과 어긋남**
- 증상: 제목/강좌명/서브슬로건 배치가 헷갈리고, 대부분 비어 있는 휴강일이 칸을 차지했으며, 이전 수기 양식엔 있던 교재 결제·수령 안내와 강의형태(현장/LIVE) 표기가 빠져 있었음.
- 원인: 초기 템플릿이 입력 양식 필드를 화면에 1:1로 옮겼을 뿐, 실제 사용 맥락(강좌명을 크게, 휴강은 진도표에서 확인, 교재 안내는 전 강좌 공통 고정문구)을 반영하지 못함.
- 대응(템플릿): 강좌명을 큰 제목으로 승격, 강의개요를 3행으로 축소(제목·휴강일 제거), 교재 안내 고정 밴드와 강의형태 배지 추가, 휴강은 진도표에 빨간색 단일 표기.

## 한계와 향후 과제

- reflow의 줄 수 계산은 글자 폭 기반 근사 추정이라, 폰트·자간에 따라 1줄 정도 오차가 날 수 있습니다.
- 입력 엑셀 양식 자체가 바뀌면 파싱 로직 수정이 필요합니다(양식 버전 관리 미구현).
- 강사 사진 매칭이 파일명 기반이라 동명이인 처리가 불가합니다.
